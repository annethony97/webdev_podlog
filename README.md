<h2>Name of Application</h2
<p>PodLog</p>


<h2>Application Description</h2>
<p>PodLog is a social-cataloging app for podcasts. Users can connect with friends, rate and share individual episodes or podcasts, find recommendations, and list and track what they're listening to.</p>
<ul>
  <li>Randomizer for recommendations for podcasts with API integration for data.</li>
  <li>Build out the social connection portion, user accounts, profiles, etc.</li>
  <li>Database and user profile tracking for current and finished, listening states.</li>
</ul>

<h2>Purpose</h2>
<p>There are a few similar apps that already exist, like Podchaser and Goodpods, but they are both listening platforms with social features, whereas this app will be solely focused on tracking and socials. Modeled similarly to Letterboxd. </p>

<h2>Target Audience</h2>
<p>Podcast Listeners</p>

<h2>Application Pages/Structure</h2>
<ul>
  <li>Sign-up/Log-in page</li>
  <li>Main Dashboard (users can see new posts from their friends or podcasts they’re following)</li>
  <li>Profile Page (shows followers and following, their logged episodes/shows, created lists)</li>
  <li>Search Function (search for shows and episodes)</li>
  <li>Recommendation Feed</li>
  <li>User unique links for sharing</li>
  <li>Episode/podcast pages</li>
</ul>

<h2>Goals</h2>
<p>1. Have a reliable and accurate search function</p>
<p>2. Have a deep catalog of podcasts to pull from </p>
<p>3. Have a proper profile set-up</p>
